DISCOVERIES

What did Rook discover instead of being told?

This is the frontier suite translated into plain English. The raw checks still exist, but they are evidence for these four capabilities rather than the product itself.

Frontier suite — Loading gates…
01
◇

Find the hidden variables that matter

Instead of accepting a human-given representation, Rook searches for latent coordinates that move consistently with interventions.

—
What does “ontology” mean?

An ontology is simply the set of variables/concepts the model believes are worth tracking. Here, Rook tries to infer those variables rather than receiving them by hand.

02
⌁

Notice when the environment changes

Rook groups periods with different statistical behavior into candidate natural experiments without receiving the regime labels.

—
Why does this matter?

A mechanism that only works in one regime is not a general explanation. Environment changes create opportunities to falsify it.

03
✦

Reject the theories it was given — then invent a new one

If none of the known mechanisms explain the evidence, Rook can assign probability to “unknown” and search residual structure for a better symbolic theory.

—
—
04
↔

Change its own concepts

When one latent variable contains two distinct behaviors, Rook can suggest a split; when two concepts collapse onto the same behavior, it can suggest a merge.

—
Is that autonomous science?

Not yet. These are controlled benchmarks with known hidden structure. The real test is whether the same machinery survives frozen prospective real-world experiments.

60-SECOND GUIDE

How to use Rook

1
Choose a target

The target changes the symbolic V0 experiment. The strategic market and physics research worlds run alongside it.

2
Read the conclusion first

Overview tells you what Rook currently believes, how confident it is, and the best next observation.

3
Open the world you care about

Market and Physics show the core loop: observe → competing explanations → diagnostic test → update.

4
Use Discoveries for the ambitious part

This is where Rook tests latent-variable discovery, theory invention, ontology changes, and prospective falsification.

5
Use Lab details only when needed

Raw R², seals, equations, and pass/fail gates are evidence for the result — not the primary experience.
